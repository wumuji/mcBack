# mcBack v1.0.0

第一个正式版。定位:**独立、轻量、开箱即用的 Minecraft Java 存档自动备份工具**。

## 下载哪个

| 文件 | 说明 |
| --- | --- |
| `mcBack-1.0.0-portable.zip` | 免安装。解压到任意目录,双击 `mcBack.exe` 即用(内置 Java 运行时) |
| `mcBack-1.0.0-Setup.exe` | 安装版。按用户安装(不需要管理员),带开始菜单与桌面快捷方式 |
| `SHA256SUMS.txt` | 校验和,可用 `certutil -hashfile <文件> SHA256` 自行核对 |

目标机器不需要安装 Java、不需要 VC++ 运行库,也不需要联网。

## 这个版本能做什么

- **自动备份运行中的存档**:不要求你退出游戏;逐文件比较复制前后的大小与修改时间,失败重试,单文件失败不中断整体任务
- **只备份你勾选的存档**,没勾的绝不碰;没勾选时不能启动自动备份
- **下次备份倒计时**(精确到秒),并显示上次备份结果、已纳入存档数量与合计大小
- **备份记录**:恢复 / 校验(SHA-256)/ 导出 / 打开目录 / 删除;按份数自动清理旧备份
- **恢复极保守**:先把当前世界改名保留为 `世界名.restore-backup-时间戳`,替换失败自动回滚,永不删除原世界;
  世界正被游戏占用时直接拒绝恢复
- 备份前检查磁盘空间;启动时检查上次残留的临时文件并让你决定如何处理
- 系统托盘、深浅色主题、按天日志(保留 14 天)

## 升级注意

- 从 0.3 及更早版本升级:配置会自动从 `%APPDATA%\MCBackup` 迁移到 `%APPDATA%\mcBack`,
  已做过的备份继续可用(程序同时识别旧清单里的 `MCBackup` 标识)。
- 旧版本如果开启过自动备份、但没有「勾选了哪些存档」的记录,升级后会**先暂停**并要求你重新勾选,
  避免把所有存档一次性全备份。
- 同一时间只允许运行一个实例:第二个实例会提示后退出。

## 已知限制

- 只支持 Windows 10 / 11 x64
- 自动备份间隔是固定档位(5/10/15/30/60/120 分钟),不支持任意分钟数与 cron 表达式
- 恢复是整目录替换,不做增量合并;备份格式是全量 ZIP(清单里已预留 `strategy` 字段给将来的增量备份)
- 外部程序无法做到「100% 原子快照」,极端情况下运行中备份可能有个别文件未能复制,备份记录里会如实标注
- 界面语言只有简体中文
